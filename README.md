# Программа по работе с банковскими счетами.
## Описание:

Данный проект исполняет функции по скрытию банковских профилей и счетов. Так же сортирует данные по статусу и дате.

## Установка:
1. Клонируйте репозиторий:
```
https://github.com/JinNazlo619/project3.git
```

## Использование:
1. Шифрование номера аккаунта. К примеру: Вводите ноемр аккаунта (73654108430135874305),а на выходе получаете зашифрованый (**4305)
2. Шифрование номера карты. К примеру: Ввод (7000792289606361), а вывод (7000 79** **** 6361)
3. Обработка данных. Сортировка по статусу или по дате и времени.
